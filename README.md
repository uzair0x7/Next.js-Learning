## 📚 About This Repository

This repository documents my journey of learning **Next.js through building projects**.

Instead of only following tutorials, I'm using practical projects to understand how Next.js works and how its different features are used in real-world applications.

The projects will gradually increase in complexity:

**Basic → Intermediate → Good → Advanced → Production-Level**

Each project is an opportunity to learn something new, experiment with different approaches, and improve my development skills.

## 💻 Running a Project

Clone the repository:

```bash
git clone https://github.com/uzair0x7/Next.js-Learning.git
```

Navigate into the project:

```bash
cd project-01
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the application:

```text
http://localhost:3000
```

> Some projects may have additional setup requirements. Check the individual project's README when available.
